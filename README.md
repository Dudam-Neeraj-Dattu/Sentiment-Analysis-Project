# Sentiment Analysis Project

This repository contains information and resources related to the sentiment analysis project.

## Rules for Pushing Changes

1. **Folder Updates**:
   - Review the contents of the folders and update them as necessary.
   - Ensure that all updates are relevant and correctly placed within the respective folders.

2. **File Naming Convention**:
   - Use the naming convention `1.x`, `2.x`, where `x` can be any integer starting from 0, to name each file within a folder.
   - This helps in maintaining a clear versioning system for each file.

3. **Subfolder Creation**:
   - If there is a need to create subfolders, name them appropriately and number them sequentially using normal integers (e.g., `1`, `2`, `3`).
   - There is no need to use the `1.x` convention for subfolder names.

4. **Versioning Files**:
   - If a folder contains a file named `1.0 progress report.pdf` and you make changes to it, save the new version as `1.1 progress report.pdf` instead of overwriting the previous one.
   - This approach allows us to easily locate the latest version and access all previous versions without relying on version control systems to trace back changes.

By following these rules, we can ensure that the project remains well-organized and that all changes are easily traceable.
